# 🏧 ATM Simulation System

## 📌 About
An ATM Simulation project that demonstrates basic banking operations through a simple interface.

## ✨ Features
- User Login
- Balance Inquiry
- Cash Withdrawal
- Cash Deposit
- transaction History

## 🛠️ Technologies Used
- Programming Language: Python
- Database: MySQL
